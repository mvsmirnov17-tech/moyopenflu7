# NEON RIFT — Arena Protocol

A small browser arena shooter built with plain HTML, CSS and JavaScript. No libraries or build tools required.

## Play locally
Open `index.html` in a modern browser.

## Controls
- **WASD / Arrow keys** — move
- **Mouse** — aim
- **Hold left mouse button** — fire
- **Space** — Rift Shift (teleport toward the cursor; damages enemies along the path)
- **Esc** — pause/resume

## Publish with GitHub Pages
1. Create a repository on GitHub, for example `neon-rift`.
2. Upload `index.html`, `style.css`, `game.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The page URL will look like `https://YOUR-USERNAME.github.io/neon-rift/`.

The game stores your best elimination count in this browser's local storage.
